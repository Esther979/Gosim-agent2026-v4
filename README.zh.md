# LLM_agent_v5.1.0_merge

基于 v5.0.3_merge 的独立提交。本轮修复邻域覆盖，保留 required 安全完成台账、B1 值班日志和地平线后验；没有加入局部指向平移或全季 required 排程。

## 完整邻域覆盖

MERGE510_NEIGHBOUR_SEARCH 默认开启，关闭后恢复 v5.0.3 查询与选场。science EV 联合搜索、骨架联合搜索和普通/强制请求选场使用同一个 FieldSearch。

每个锚点一次粗筛：包围半径由当前实际枚举光纤的最大球面偏移加方形视场的角距推导，保留至少旧查询半径，另留四位小数舍入余量。每个实际指向用单位向量点积筛除不可能进入视场的目标，再走原 gnomonic 投影、光纤间隙和边缘 margin 检查。收益在目标确实落入光纤后按需计算，原收益缓存、曝光候选与排序规则保留。

空间索引缓存赤纬带的 RA keys，使用球面包围圆的赤经范围，处理 0/360° 回绕及跨极点全 RA 查询。目标向量缓存局限于本次搜索，不跨时刻复用。最终 trace 增加 merge510_spatial_final，记录查询、粗筛候选及向量构建计数。

B 公开首夜 100 个锚点、2,495 个候选指向均用完整可见星表独立投影核对：原方法 504 个视场漏查，本版本 0 个。恢复了 1,357 次候选出现，其中 52 次 required 出现对应 20 个不同目标；这不是完整赛季完成数量或分数。

## required 完成台账

入口改用 GuardedSurveyState 子类。每次有效回执按公开声明倍率与 mismatch 倍率的最大值，计算扣除六位小数舍入半单位后的 factor 安全下界。多次有效曝光取最大值，不相加；缺失 hit、零分、无效曝光不增加完成度。required 只在安全下界越过 initialize.scoring 的完成阈值后退出必拍状态。

子类在原 on_result 完成科学/天气/故障估计之后，用独立下界替换 required 的规划 factor。因此候选排序、联合选纤、时长及请求检查都能看到保守完成状态，非 required 的估计保持原样。resync 移除失效动作的下界证据；保留已知有效回执的声明倍率信息，未知历史使用公开最大倍率兜底。程序加成不能代替真实物理深度。

## B1 值班日志

识别 new_messages 或 active_requests 中 observation_request.reason 的日志文本；不因请求奖励为零而丢弃。解析接口带完整归一化原文、发布时间、站点 UTC 偏移、巡天日期范围及此前接受的事实。解析明确订正、暗号规则及跨行上下文，只输出有原文依据的地形高度和有起止时间的天气。正常观测请求不触发此接口。

每段 request_id/文本哈希最多尝试一次、每晚最多一次；最多 32 次，总解析耗时不超过共享 LLM 预算的 24% 或 120 秒中较小者，每次最多 25 秒且不重试，剩余总预算不足 120 秒时不调用。与夜间建议和 miss triage 共享调用及时间上限；临时 token/provider 参数在 finally 中恢复。

高度以至少 ±1° 的区间和至多 0.98 的模型置信权重进入后验，不写死本次 B1 的数值。只有方位词时，使用中心 45° 方位区间作为建模假设，区间外保留原回退；这不是对真实山脊边界的保证。公开日志先验可从收到时使用，普通观测仍按前五晚校准。未含日志的方向与 v5.0.2 相同。

天气转换为 UTC 后只在该时间段有效。明确全天关闭且解析置信度至少 0.95 时等待下一简报时隙；将未来全天关闭起点作为曝光长度边界。方向性坏天气仅软降优先级，避免永久封锁整个方向。与曝光重叠的日志天气将样本标为不适于故障/地平线校准。预测信息仍可能有误，解析置信度不是经校准的概率。

新文本或明确引用原事实和当前订正文的撤销可以更新缓存。解析异常、超时、无依据输出不会触发任意动作；空解析不能清除旧事实。默认 HTTP 接口、科学 EV、共同曝光收益、预算 pacing 和故障处理保留。

## 运行与验证

manifest 默认 MERGE510_NEIGHBOUR_SEARCH=1、MERGE503_REQUIRED_GUARD=1、MERGE503_DUTY_LOG=1。单独设为 0 可做消融；关闭 MERGE510_NEIGHBOUR_SEARCH 后两个均为 0 是 v5.0.2 控制。MERGE501_MODULES、MERGE502_HORIZON、MERGE502_MISS_LLM 保留原用途。

```sh
python3 run_merge510_all8.py deepseek --jobs 8
```

八张本地练习卡是 L1、L2、L3、L4、alpha、beta、gamma、delta。固定夜间建议回放关闭所有 API，可用于邻域修复的消融，但不能证明日志真实解析效果；B/B1 正式天气不公开，正式提分仍须平台评测。验证记录在包外 experiments/merge_v510。不要上传 .env、凭据、日志、测试或回放数据。

本地 live 调试默认读取组委会 `.env.example.deepseek`；`--env-file` 可显式覆盖。离线回放不读取默认凭据。提交包不含任何密钥，仍用平台注入的 API 配置。
